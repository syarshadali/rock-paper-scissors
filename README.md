# rock-paper-scissors

This is the third foundations and the first javascript project of the full stack development course of The Odin Project.

<b>INTRODUCTION:</b>

This is the popular rock-paper-scissors game which is designed through javascript language and will be played entirely on browser's console. The UI will be created later.

<b>OBJECTIVE:</b>

The main objective of this rock-paper-scissors game is to demonstrate the use of browser's console which is a built-in development tool which provides the ability to write, manage, debug, monitor and run javascript code on demand.

<b>SKILLS DEMONSTRATED:</b>

<ol>
    <li>Logging messages in the console of the browser by the use of console.log()      method which is a built-in function for debugging code, It allows developers to track the flow of execution of the javascript code.</li>
    <li>The use of variables as containers for storing data values for holding information that can be used and modified throughout a program's execution.</li>
</ol>
