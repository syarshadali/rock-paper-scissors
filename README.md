# rock-paper-scissors

This is the third foundations and the first javascript project of the full stack development course of The Odin Project.

<b>INTRODUCTION:</b>

This is the popular rock-paper-scissors game which is designed through javascript language. The game will be played through UI by clicking the buttons in the UI.

<b>OBJECTIVE:</b>

The main objective of this rock-paper-scissors game is to demonstrate the use of UI as well as browser's console which is a built-in development tool which provides the ability to write, manage, debug, monitor and run javascript code on demand.

<b>GAME FUNCTIONALITY:</b>

The game will be played in the UI by clicking buttons and when the score reaches 5, winner or loser is declared and play again button will reveal to reset the game, the buttons will not be disabled.

<b>SKILLS DEMONSTRATED:</b>

<ol>
    <li>Logging messages in the console of the browser by the use of console.log()      method which is a built-in function for debugging code, It allows developers to track the flow of execution of the javascript code.</li>
    <li>The use of variables as containers for storing data values for holding information that can be used and modified throughout a program's execution.</li>
    <li>Functions are used in the project which are reusable blocks of code designed to perform specific tasks. This is called Modular Programming. </li>
    <li>The use of Math.random() and the Math.floor() built-in functions to generate random whole numbers.</li>
    <li>When we click the buttons in the UI, an event occurs which is tracked by addEventListener() method which is the recommended mechanism for adding event listeners.</li>
    <li>The if...else conditional statement to execute different blocks of code based on whether a specified condition is true or false.</li>
    <li>String Concatenation to concatenate (join) strings using several methods such as the + operator, template literals (backticks), etc.</li>
    <li>The increment operator(++).</li>
    <li>Using git for version control and navigating files and directories in Linux system through terminal.</li>
</ol>
